Introducción al HTML

HTML se utiliza para crear páginas web. Consta de un conjunto de elementos, denominados etiquetas, que se usan para incluir textos, imágenes, tablas, etc. La mayoría de las etiquetas se desdoblan en dos, una de comienzo y otra de fin; y un conjunto de atributos.

NO es una etiqueta HTML. En realidad, es un elemento de SGML ("Lenguaje de Marcas Generalizado Estándar"). HTML es, en realidad, un lenguaje escrito en SGML.

Elementos de la Cabecera

  • <title>: título de la página que aparecerá en los navegadores. Los buscadores lo utilizan para clasificar las páginas.
  • <link>: para relacionar documentos como las hojas de estilo.
  • <meta>: sirve para incluir información sobre el autor de la página, nombre del editor de HTML, una descripción breve de la página, etc.

Descripción de Meta Tags

El meta tag <meta name="nombre" content="contenido"> puede contener:

  • description: Describe el contenido de la página.
  • keywords: Lista de palabras clave relacionadas con el tema de la página.

Enlaces e Hiperenlaces

Código HTML

<!-- Al mismo documento -->

<a href="#nombre"> Texto del enlace </a>

<!-- A otros documentos -->

<a href="destino"> Texto del enlace </a>

<!-- A contenidos especiales -->

<a href="archivo.ps"> Enlace a un archivo Postscript </a>
<a href="mailto:usuario@direccion"> Enviar un email </a>

Tablas

<table> ... </table>
  • <th>: Celda cabecera de una tabla.
  • <caption>: Asigna un título a la tabla.
  • <tr>: Marca el comienzo de una fila de la tabla.
  • <td>: Celda de datos de una tabla.

Formularios

Los formularios permiten la interacción entre el código HTML y los scripts. Son usados para enviar y recibir datos, proporcionando retroalimentación al sistema de información.

Atributos en Formularios

  • autocomplete: autocompleta el input basado en valores previos del usuario.
  • novalidate: especifica que los datos del formulario no deben ser validados al enviarse.
  • autofocus: recibe automáticamente el foco cuando se carga la página.
  • placeholder: muestra una sugerencia en el campo de entrada.
