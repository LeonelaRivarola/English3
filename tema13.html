AJAX: Asynchronous JavaScript and XML

¿Qué es AJAX?

AJAX (Asynchronous JavaScript and XML) es una técnica de desarrollo web utilizada para crear aplicaciones interactivas (RIA). Permite la comunicación entre el cliente y el servidor de manera asíncrona, lo que significa que se pueden solicitar datos sin recargar toda la página.

Tecnologías que componen AJAX

  • JavaScript: Para interactuar con el cliente y manipular el contenido de la página.
  • XHTML: Para estructurar la información.
  • CSS: Para dar estilo a la presentación.
  • XML y JSON: Para el intercambio de datos entre el cliente y el servidor.
  • DOM (Document Object Model): Para manipular dinámicamente la estructura de la página.
  • XMLHttpRequest: Para realizar las peticiones asíncronas al servidor.

Funcionamiento de AJAX

1. Evento del usuario: Cuando el usuario interactúa con la página (por ejemplo, haciendo clic en un botón), se crea un objeto de AJAX usando XMLHttpRequest.

2. Petición al servidor: El objeto AJAX envía una petición al servidor con un método GET o POST.

3. Procesamiento del servidor: El servidor procesa la petición y envía la respuesta, que puede ser un archivo XML o JSON.

4. Actualización de la página: El cliente procesa los datos recibidos y actualiza la página sin necesidad de recargarla.

Diferencia entre Modelo Tradicional y Modelo AJAX

Característica Modelo Tradicional Modelo AJAX
Recarga de la página Cada interacción con el servidor provoca la recarga completa de la página. Permite actualizar partes de la página de manera dinámica sin recargarla por completo.
Experiencia del usuario La recarga completa de la página puede hacer que la experiencia del usuario sea más lenta y menos fluida. Mejora la experiencia del usuario al permitir una navegación más rápida y dinámica.
Uso de recursos El modelo tradicional puede usar más recursos debido a la recarga completa de la página. AJAX usa menos recursos al cargar solo las partes necesarias de la página.

Consideraciones de uso de AJAX

  • Problemas con el historial: Las páginas generadas por AJAX no se registran automáticamente en el historial del navegador.
  • Problemas de accesibilidad: Algunas aplicaciones AJAX pueden no ser completamente accesibles para personas con discapacidades si no se implementan correctamente.
  • Política de mismo origen: Los navegadores bloquean las peticiones AJAX a dominios diferentes al servidor original. Se puede solucionar con CORS.

Ejemplo

de aplicación AJAX

Este es un ejemplo básico de cómo cargar contenido asíncronamente usando AJAX:


    <!DOCTYPE html>
    <html>
    <head>
        <title>AJAX Ejemplo</title>
        <script type="text/javascript">
            function cargarContenido() {
                var peticion_http = new XMLHttpRequest();
                peticion_http.onreadystatechange = function() {
                    if (peticion_http.readyState == 4 && peticion_http.status == 200) {
                        document.getElementById("contenido").innerHTML = peticion_http.responseText;
                    }
                };
                peticion_http.open('GET', 'archivo.txt', true);
                peticion_http.send(null);
            }
        </script>
    </head>
    <body>
        <button onclick="cargarContenido()">Cargar Contenido</button>
        <div id="contenido"></div>
    </body>
    </html>
