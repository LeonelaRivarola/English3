Introducción a PHP

¿Qué es PHP?

PHP es un lenguaje de script del lado del servidor, similar a ASP, JSP o ColdFusion. Los scripts PHP se incrustan en documentos HTML, el servidor los interpreta y ejecuta antes de mostrar la página al cliente. El cliente solo ve el resultado, no el código.

Introducción a PHP

PHP es un lenguaje de programación del lado del servidor ideal para crear sitios web dinámicos.

Ventajas de PHP

Fácil de aprender, potente y ampliamente soportado por una comunidad activa.

Sintaxis de PHP

Fácil de integrar con HTML, lo que permite desarrollar aplicaciones web rápidamente.

¿Por qué PHP?

Ventajas: PHP es potente, fácil de aprender, tiene distribución libre y ofrece acceso a bases de datos y otras funcionalidades orientadas a la red. Además, cuenta con un amplio soporte en la web.

Sintaxis básica de PHP

PHP es sensible a las mayúsculas. La forma de incrustar código PHP es:

<?PHP ... ?>

O también se puede usar:

<?= expresión ?>

Para imprimir en pantalla, se usa echo o print.

Ejemplo básico:

<HTML>
    <HEAD>
        <TITLE>Mi primer programa en PHP</TITLE>
    </HEAD>
    <BODY>
        <?PHP
        print ("Hola mundo");
        ?>
    </BODY>
</HTML>

Inclusión de archivos externos

  • include() y require(): ambos incluyen y evalúan el archivo especificado.
  • Diferencia: include() produce un warning si hay error, mientras que require() detiene la carga de la página con un error fatal. Se usa require() cuando el error debe interrumpir la carga.

Tipos de Datos en PHP

PHP soporta 8 tipos básicos de datos:

  • Escalares: boolean, integer, double, string.
  • Compuestos: array, object.
  • Especiales: resource, NULL.

Ejemplo de uso de var_dump:

$x = 10.5;
        var_dump($x);

Variables en PHP

  • Declaración: Comienzan con $ y son sensibles a mayúsculas.
  • Ámbito: Global o local dentro de funciones.
  • Predefinidas: $_GET, $_POST, $_SESSION, etc.

Ejemplo de Variable:

$valor = 5;
        print $valor;

Constantes

  • Definición: Usar define() y no lleva $.

Ejemplo de Constante:

define("CONSTANTE", "Hola");
        print CONSTANTE;

Operadores

  • Aritméticos: +, -, *, /
  • Comparación: ==, !=, <,>
  • Lógicos: and, or, &&, ||

Estructuras de Control

  • if-else: Ejecuta código si se cumple una condición; si no, ejecuta el bloque else.
  • while: Ejecuta código mientras la condición sea verdadera.
  • do-while: Similar al while, pero garantiza que el código se ejecute al menos una vez.
  • for: Ejecuta código un número determinado de veces.
  • foreach: Recorre arrays y ejecuta código para cada valor.
  • switch: Ejecuta bloques de código según el valor de una variable.
