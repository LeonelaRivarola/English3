Hojas de Estilo en Cascada (CSS)

Características

  • Mejora la apariencia y flexibilidad.
  • Reduce la complejidad.
  • Facilita la accesibilidad para personas con discapacidades.

¿Qué son?

CSS permite separar la logica y el fisico, mejorando la estructura y el mantenimiento del código.

¿Cómo funciona?

HTML define los elementos de la página y CSS aplica estilos a esos elementos.

Ventajas

  • Puede estar en el mismo archivo HTML o en un archivo externo.
  • Permite reutilizar estilos en múltiples documentos.
  • Admite estilos alternativos para diferentes medios.

Formas de aplicar

  • <style>: al comienzo del documento.
  • style="": como atributo en un elemento específico.
  • <link>: para enlazar una hoja de estilos externa.
  • @import: para importar un archivo de estilos.

CSS

Selectores

  • Selector de tipo: aplica estilos a etiquetas HTML.
  • Selector universal (*): aplica estilos a todos los elementos.
  • Selector de clase: usa un punto (.).
  • Selector de ID: usa un símbolo de número (#).

Pseudo-clases y Pseudo-elementos

  • :hover: cambia el estilo cuando el usuario pasa el mouse.
  • ::before: inserta contenido antes de un elemento.
  • ::after: inserta contenido después de un elemento.

Propiedades CSS

  • Fuente: font-family, font-size, font-weight.
  • Color: color, background-color, background-image.
  • Texto: text-align, text-decoration, letter-spacing.
