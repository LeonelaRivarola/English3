Lenguaje JavaScript

¿Qué es JavaScript?

JavaScript es un lenguaje de scripting basado en objetos utilizado para desarrollar aplicaciones cliente-servidor en Internet. Se embebe en documentos HTML y permite responder a eventos de usuario sin conexión a la red.

¿Cómo se ejecuta JavaScript?

JavaScript puede ejecutarse del lado del cliente en el navegador o del lado del servidor con entornos como Node.js. En los documentos HTML, el código JavaScript se incluye dentro de las etiquetas <script> y se interpreta al cargar la página.

Comparativa: Java vs JavaScript

Java es un lenguaje compilado, orientado a objetos, y más robusto. Por otro lado, JavaScript es interpretado, más flexible, y usado principalmente para interacciones web rápidas.

Comentarios en JavaScript

  • Una línea: // Este es un comentario
  • Multilínea: /* Este es un comentario multilinea */

Estructura del Código

Las sentencias terminan opcionalmente con punto y coma (;), lo cual mejora la claridad del código. Ejemplo: document.write("Hola Mundo");

Impresión

  • document.write: Escribe texto o código HTML en el documento. Ejemplo: document.write("Hola JavaScript");
  • alert: Muestra un mensaje en una ventana emergente. Ejemplo: alert("Hola JavaScript");

Variables y Constantes

  • Declaración: var, let, const
  • Tipos de datos: Cadenas, números, booleanos

Operadores

  • Aritméticos: +, -, *, /, %
  • De comparación: ==, !=, >, <=< /li>
  • Lógicos: &&, ||, !

Control de Flujo

  • Condicionales: if, else if, else
  • Bucles: for, for...in, while

Entrada/Salida

  • Alert: Muestra un mensaje informativo.
  • Confirm: Mensaje con opciones.
  • Prompt: Solicita entrada del usuario.
  • Console: Para debugging con console.log.

¿Qué es el DOM?

El DOM (Document Object Model) es una interfaz que permite representar y manipular documentos HTML y XML de manera estructurada.

¿Qué permite hacer el DOM?

  • Cambiar contenido: document.getElementById('titulo').textContent = 'Nuevo título';
  • Agregar elementos: document.createElement('p');
  • Eliminar elementos: document.getElementById('elemento').remove();
  • Modificar estilos: document.getElementById('caja').style.backgroundColor = 'red';

Eventos en JavaScript

Usando addEventListener, se pueden asignar eventos a elementos HTML. Ejemplo:

boton.addEventListener("click", function() { alert("Botón clickeado"); });

jQuery

¿Qué es jQuery?

  • Biblioteca multiplataforma de fácil aprendizaje.
  • Simplifica tareas complejas de JavaScript como llamadas AJAX y manipulación DOM.

Características principales

  • Manipulación HTML / DOM.
  • Manejo de CSS.
  • Métodos para eventos HTML.
  • Animaciones y efectos.
  • Soporte para AJAX.

Ventajas de usar jQuery

  • Popular y ampliable.
  • Utilizado por grandes empresas como Google, Microsoft, IBM y Netflix.
  • Compatible con frameworks como Bootstrap.

Formas de uso de jQuery

<script src="jquery-3.5.1.min.js"></script>
<script src="https://ajax.googleapis.com/ajax/libs/jquery/3.5.1/jquery.min.js"></script>

Sintaxis básica de jQuery

$(selector).action()

// Oculta un elemento
$(this).hide();

// Ocultar párrafos al hacer clic
