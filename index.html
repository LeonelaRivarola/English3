Introducción a Internet y la Web

Internet es un conjunto de redes interconectadas que permiten el acceso a información y servicios.

Características

  • - Acceso público y privado
  • - Gran número de usuarios
  • - Requiere seguridad

Intranet vs Extranet

Intranet: Red privada con acceso restringido.

Extranet: Red privada con acceso desde Internet, usada por empresas.

Etapas de la Web

  • Web 1.0: Contenido estático y pocos productores.
  • Web 2.0: Interacción y contenido colaborativo.
  • Web 3.0: Uso de inteligencia artificial y bases de datos.
  • Web 4.0: Comunicación entre máquinas y asistentes de voz.
